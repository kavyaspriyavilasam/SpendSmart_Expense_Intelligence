Project Overview

SpendSmart is an expense analysis dashboard created with Microsoft Power BI. It helps explore spending patterns and understand how expenses vary across categories, payment methods, and months.

Objectives

- Analyze total expenses and transaction counts.
- Compare expenses across categories.
- Understand spending by payment method.
- Explore monthly expense trends.
- Use interactive slicers to filter the report.

Tools Used

- Microsoft Power BI Desktop
- Power Query for data import and preparation
- DAX for measures
- CSV sample dataset

Dataset

The dataset contains 72 sample expense records from January to June 2026, with fields including date, category, subcategory, merchant type, amount in INR, and payment method.

Note: This is a sample dataset created for portfolio and learning purposes, not real personal financial data.

Key Measures

- Total Expenses: Sum of expense amounts.
- Total Transactions: Count of expense records.
